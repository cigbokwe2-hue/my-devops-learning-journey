## How this repo works

- **[ROADMAP.md](ROADMAP.md):** my plan, and every topic as a checkbox. It's the one place my progress is tracked.
- **[journal/](journal/):** one entry per study day: what I did, what I learned, what confused me, and where to pick up next time.
- **[phases/](phases/):** a folder for each phase, created the day it starts, with my notes, labs and a retro.
- **[templates/](templates/):** the blank pages I copy for each of those.
- **Capstone:** my learning tracker, grown into a web app one phase at a time. It gets its own repo in Phase 4.

A topic only counts as done when I've learned it, explained it in my own notes, and done it myself in a lab.
